# WebPilot 设计文档

WebPilot 是面向开源技术选型的浏览器调研助手。用户提交调研问题，系统检索公开资料、按需浏览页面、保存证据并生成带引用的报告。项目借鉴 pydantic-ai-autobrowser 的规划、执行、检查循环，独立重新设计；本文档描述计划实现的系统，不代表功能已经完成。

## 文档目录

1. [需求文档](./requirements.md)：目标、用户流程、首版范围和验收标准。
2. [架构与数据设计](./architecture.md)：模块、任务状态、证据模型、异常处理与安全边界。
3. [接口文档](./api.md)：HTTP API、事件流、数据结构和错误约定。
4. [Agent 协议](./agent-contracts.md)：各 Agent 的结构化输入输出、校验与引用生成。
5. [开发与评测计划](./delivery.md)：里程碑、测试数据、评测口径与交付标准。
6. [前端页面设计](./frontend-design.md) 与 [三套模板预览](./frontend-options.html)：页面、状态、视觉方向和可本地打开的交互示例。

## 阅读约定

- **P0** 为首个可运行版本必须实现的功能；P1 为之后迭代，不计入首版验收。
- 默认单机、单用户、本地部署；对外开放或多人使用前需要重新设计认证和隔离。
- 开发之前需要确认模型和搜索服务的可用性及费用；供应商通过适配器替换。
- GitHub 参考项目：[pydantic-ai-autobrowser](https://github.com/spichkinevgeniy/pydantic-ai-autobrowser)。参考其设计或代码时保留来源和适用的 MIT 许可声明。

当前版本：0.3（第二轮评审）。修正了预算不可达、采集提交、Writer 覆盖校验和评测对照组问题，并同步接口示例。所有能力仍为待实现设计。

设计约定以各专题文档为准：状态/恢复/预算见架构，HTTP 字段见接口，模型输出见 Agent 协议；后续修改必须同步对应验收用例。当前不再增加 P0 功能，先完成技术验证再实现。
