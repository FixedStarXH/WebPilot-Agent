# 开发、测试与评测计划

## 1. 开发顺序

| 阶段 | 目标 | 交付与验收 |
|---|---|---|
| 0 | 技术验证 | 确认 Python、模型、搜索、Playwright MCP 和浏览器隔离在目标环境可用；记录服务费用和限制。若浏览器隔离不可用，首版关闭回退。 |
| 1 | 任务基础设施 | FastAPI、PostgreSQL、迁移、任务状态、事件、单 worker 租约、取消和恢复；使用假工作流验证并发与重启。 |
| 2 | 调研闭环 | 模型规划、搜索适配器、安全抓取、证据提取、引用校验、报告生成；使用固定数据和假服务完成自动化集成测试。 |
| 3 | 浏览器与界面 | 配置受限浏览器回退；实现新建任务、事件流、来源和报告页面、导出；覆盖失败和重连场景。 |
| 4 | 实际验证 | 执行真实服务端到端样例；构建评测集，记录结果、失败原因、耗时、调用成本和可复现配置。 |

首版以阶段 1–4 的验收通过为准；浏览器隔离未就绪时，阶段 3 可按关闭浏览器回退交付，并在界面和文档说明能力受限。文档上传、登录及敏感操作属于 P1，另行设计后实施。

## 2. 测试策略

- **单元测试**：状态转换、输入边界、URL 去重和地址校验、证据 ID 引用校验、Markdown 导出。
- **集成测试**：使用假模型和假搜索/抓取服务，验证创建 → 规划 → 采集 → 检查 → 报告；覆盖无来源、部分来源失败、模型超时和引用不存在。
- **状态与并发测试**：两个 worker 竞争同一任务仅一个领取；取消在检查点生效；模拟 worker 中断、租约过期、恢复和重复请求；检查步骤与证据不会因重试无界重复。
- **API 与事件测试**：验证状态码、参数约束、404/409/422、分页；SSE 断线后按游标补齐，事件去重且终态关闭。
- **安全测试**：拒绝本地、私网、重定向至内网和非 HTTP(S) URL；测试 DNS 重绑定防护和浏览器子资源网络策略；检查网页注入文本无法改变工具权限。浏览器隔离未通过时不能启用回退。
- **端到端测试**：在可用密钥和网络的环境执行真实任务，人工核对报告引用和网页内容；测试记录避免包含密钥及私人数据。

## 3. 评测集与指标

首版准备至少 20 条人工整理的公开技术选型问题，覆盖单项目事实、多项目对比、不同来源冲突、资料缺失和动态页面。每条记录问题、预期覆盖点、可接受的参考来源或人工核对方法；记录测试日期，因为信息会变化。不要把搜索服务返回结果直接当作标准答案。

| 指标 | 计算方式 | 局限 |
|---|---|---|
| 任务完成率 | 人工判定完成任务数 / 总任务数 | 需提前制定评分标准，不能仅以 API 返回 completed 代替 |
| 引用可访问率 | 抽查时可访问的引用链接数 / 抽查引用数 | 随时间和网络变化 |
| 引用支持率 | 人工判定片段支持所对应结论的引用数 / 抽查引用数 | 不等于全文事实正确率 |
| 信息覆盖率 | 报告覆盖且有证据的预期要点数 / 预期要点总数 | 依赖评测集标注质量 |
| 延迟与成本 | 从任务开始到终态的时长；按服务商实际用量及价格统计费用 | 未返回用量或无法确定价格时记未知，记录模型及价格日期 |

对比实验：固定任务集、模型与限制，对比启用/禁用补充检索时的完成率、引用支持率、耗时与费用（两组均保留 Reviewer，保持 Writer 输入协议一致）；每组至少运行一次，记录随机性，结果不足以推断总体显著性。仅在真实测量后写入简历，不预设提升幅度。

## 4. 项目交付物

- 运行说明：依赖、环境变量样例、启动方式、配置搜索和模型、限制及退出清理。
- 可运行系统及自动化测试；不提交密钥、浏览器资料或用户数据。
- 示例任务、报告和评测记录，区分假数据与真实数据。
- 架构图、状态流转、接口说明及关键设计取舍。
- 来源与许可证说明：清楚区分参考项目、使用的依赖和本人实现。

## 5. 目前需要确认的产品决策

- 首版使用哪家模型与搜索服务；取决于用户可用账号、网络和费用预算。
- 前端框架按开发者熟悉程度选择；当前文档不强制 Vue 或 React。
- 浏览器隔离能否在目标 Windows 环境可靠配置；无法满足时降级为安全 HTTP 抓取。

## 6. 本次评审补充的验收用例

| 编号 | 情景 | 预期 |
|---|---|---|
| AT-01 | 用同一幂等键重复创建或恢复 | 不新增任务/attempt，返回原响应；改请求内容则 409 |
| AT-02 | 同一报告部分子问题缺少证据 | completed + partial，列出缺失项；无支持证据则 failed/NO_EVIDENCE |
| AT-03 | 旧 worker 租约过期后迟到提交 | 所有表均拒绝写入，不污染新 attempt 的证据、报告与事件 |
| AT-04 | 取消与报告完成同时发生 | 按事务提交顺序裁决，不出现 cancelled 任务新增正式报告 |
| AT-05 | 任务恢复后 SSE 重放旧终态 | 展示历史事件但不误关闭当前 attempt；游标补齐无遗漏 |
| AT-06 | 恢复时协议或配置变化 | 返回 RESUME_INCOMPATIBLE；不使用不兼容检查点 |
| AT-07 | 模型返回虚构引用或改写的“原文” | 应用校验拒绝，最多修复一次；不能生成表面有效的报告 |
| AT-08 | 浏览器隔离不可用 | capabilities 显示禁用，界面提示 HTTP 模式，不调用 MCP 浏览器 |
| AT-09 | 达到模型请求、步骤、来源或恢复次数限制 | 按预算规则停止，不允许恢复无限规避费用上限 |
| AT-10 | 终态任务清理后查看来源和报告 | 404；相关缓存、幂等记录清除；运行任务禁止清理 |

补充交付：开发时从 Pydantic/FastAPI 模型生成 OpenAPI 契约并校对本文档；数据库迁移包含外键、唯一约束和索引。当前 Markdown 示例不替代机器可校验的 OpenAPI Schema。

实际浏览器样例至少包含一个公开动态页面；若未完成隔离或实测，只能交付 HTTP 调研版本，不能在简历中写成已完成浏览器 MCP 能力。消融实验固定同一批初始采集文本，比较补充检索上限为 0 和 2 的版本，两组均保留最终 Reviewer；预录可供补充检索的响应用于离线重放，并单独记录真实在线结果。不得把该实验宣称为有/无 Reviewer 对比。


## 7. 第二轮评审验收补充

| 编号 | 情景 | 预期 |
|---|---|---|
| AT-11 | 最大计划和 20 个来源 | 逻辑步骤上限可容纳流程；测试用假时钟验证预算预留，不强求真实网络 10 分钟内完成 |
| AT-12 | 采集返回后、提交前 worker 中断 | 来源不留下半完成证据；恢复重试不重复占来源名额 |
| AT-13 | 全部子问题 supported，但 Writer 漏写一项 | 触发输出修复；不能直接返回 complete 或 partial |
| AT-14 | Reviewer 判定所有来源都不足或冲突 | NO_EVIDENCE，不生成无支持结论的正式报告 |
| AT-15 | 模型派发后崩溃 | 调用名额已计数，用量 unknown；不得记为零费用 |
| AT-16 | 清理终态任务与恢复同时请求 | 任务行锁串行裁决；无恢复后的运行任务被删除 |
| AT-17 | 超过模型上下文预算 | 按子问题选取完整证据片段；不提交超长请求，未见证据不用于支持判定 |

完成率人工评分规则：仅当问题中的每个必需维度均已回答、事实有支持来源且无关键错误，记为完成；明确指出确实不可获得的信息可按预先标注的可接受答案计分。partial 不自动算通过，也不自动算失败。每条问题预先标注维度，禁止看完输出后调整标准；无引用样本的引用比例记 N/A，同时纳入任务失败计数。开发用例与保留评测集分开，保留集在验收时运行。
